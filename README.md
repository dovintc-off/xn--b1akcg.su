# **КВИЗ.SU (Free quizzes)**

> **Свободный интернет — это право каждого.**<br>
> Проект создан с целью сделать знания доступными для всех, без капиталистических ограничений и скрытых платежей.

**КВИЗ.SU** — это платформа для создания и прохождения бесплатных викторин. Проект разработан с упором на производительность, открытость кода и независимость от внешних сервисов.

## **Основные идеи**
*   **Свобода доступа:** Никакой платной подписки или скрытого контента.
*   **Открытый код:** Вы можете изучать, изменять и улучшать проект.
*   **Приватность:** Мы не следим за пользователями. Интернет должен оставаться свободным от тотальной слежки.

## **Технологии**
Проект разрабатывается с использованием современных подходов к веб-разработке:
*   **Backend:** Python 3.14+, Gunicorn, Flask, Flask-SocketIO
*   **Frontend:** Чистый HTML/CSS/JS (без тяжелых фреймворков для максимальной скорости)
*   **Web Server:** Nginx (рекомендуется для продакшена)

## **Установка и запуск**

### Требования
*   Python 3.14+
*   Nginx (опционально, для проксирования)
*   Все библиотеки из `requirements.txt`

### Инструкции

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/dovintc-off/xn--b1akcg.su.git
    cd xn--b1akcg.su
    ```

2.  Создайте и активируйте виртуальное окружение:

    **Windows:**
    ```bash
    python -m venv venv
    venv\Scripts\activate
    ```

    **Linux / macOS:**
    ```bash
    sudo apt install python3-venv  # Только если venv еще не установлен
    python3 -m venv venv
    source venv/bin/activate
    ```

3.  Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```

4.  Запустите проект:

    **Для разработки (простой запуск):**
    ```bash
    python app.py
    ```

    **Для продакшена (два варианта):**
    ```bash
    gunicorn --worker-class geventwebsocket.gunicorn.workers.GeventWebSocketWorker -w 1 -b 127.0.0.1:5000 app:app
    sudo systemctl start quiz-su # Для линукс, требуется предварительная настройка unit-файла и работа с systemctl
    ```

    **[Подробнее о unit-файлах и systemctl](https://ru.wikipedia.org/wiki/Systemd)**
5.  Откройте браузер по адресу `http://localhost:5000`
